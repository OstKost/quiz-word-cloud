# Текущее состояние

Реализовано: комнаты, форма телефона, экран ведущего и проектора, нормализация одинаковых ответов, частота по уникальным участникам, лимиты и задержка между отправками, серверный фильтр, пауза/стоп/таймер, скрытие слова, новый раунд, D1-схема, локальный SQLite-сервер, адаптивный интерфейс, canvas-анимация с входом с края и ростом размера.

Автоматические проверки: жизненный цикл комнаты, права управления, конкурентные лимиты, фильтр, скрытие, таймер, сохранение базы, модель 200 слов и смена лидера. Модель проверяет отсутствие наложений после стабилизации, границы экрана, минимум 14 px и время расчёта. Она не заменяет проверку производительности отрисовки на реальном устройстве.

Не завершено:
- Проверка интерфейса в настоящем браузере и на телефоне. Локальный сервер не смог открыть порт (`EPERM`); браузер запрещает `file://`.
- Публикация. Site зарегистрирован, ID сохранён в `.openai/hosting.json`; версия не опубликована. Source helper в `/private/tmp/slovopotok-publish` завершился с `Could not resolve host: git.chatgpt-team.site`. Git основной папки защищён от записи.
- Проверка применения D1-миграции и всего сценария на размещённом сайте.
- Выбор доступа: пользователь получил вопрос о публичной ссылке Sites, своём сервере или локальной Wi-Fi сети. Sites пока приватный, доступ не изменялся.

Цель «под ключ» остаётся открытой до публикации/выбранного запуска и проверки с двух устройств. Не выдавать expected_url за рабочую ссылку.
